# Trend Detective

Team **Sunway to the Moon**, NASA Space Apps Challenge 2026 (Kuala Lumpur).
Challenge: *Be An Earth System Trend Detective!*

`main` holds the project structure only. Each team member works on their own branch
(`danny`, `barry`, `weiling`, `waikang`, `mingen`, `ryan`) and opens a pull request into `main`.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Page layout; loads every script below |
| `style.css` | All styles |
| `globe.js` | Interactive 3D Earth globe |
| `stats.js` | Trend and significance statistics |
| `app.js` | Main app: data loading, charts, results |
| `i18n.js` | Translations |
| `maplab.js` | Trend maps and timelapse |
| `stories.js` | Guided stories |
| `ask.js` | Question box |
| `polish.js` | UI polish |

## Run it

Open `index.html` in a browser. Nothing to install or build.

## Workflow

```
git checkout <your-name>
# make changes
git add -A && git commit -m "what I changed"
git push
```
Then open a pull request from your branch into `main` on GitHub.
