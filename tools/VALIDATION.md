# Statistics validation

Generated by `tools/coverage.py` on 2026-11-14 with 2000 simulated series per row (half with a true trend of +0.2 per decade, half with none). Noise standard deviation 0.3.

| Scenario | 95% interval contains the true trend | False alarms, Mann-Kendall | False alarms, t-test | Real trend detected |
|---|---|---|---|---|
| Yearly, 45 years, independent noise | 94.8% | 5.0% | 5.0% | 100.0% |
| Yearly, 45 years, autocorrelated noise (r1 = 0.3) | 84.8% | 14.8% | 14.4% | 99.8% |
| Monthly, 540 months, r1 = 0.6, no correction | 68.0% | 28.8% | 30.0% | 100.0% |
| Monthly, 540 months, r1 = 0.6, corrected (what the site does) | 94.3% | 4.0% | 4.6% | 100.0% |

Targets: about 95% coverage and about 5% false alarms.

- Independent yearly noise: the tests behave as promised.
- Autocorrelated yearly noise makes the plain tests overconfident; the website shows a caution note when lag-1 autocorrelation is strong.
- Monthly data without a correction would be badly overconfident. The website corrects monthly data for autocorrelation, which brings coverage and false alarms back near their targets.

`tools/validate_stats.py` separately checks every number stats.js reports against SciPy (`linregress`, `theilslopes`, `t`, `norm`) and textbook formulas.
